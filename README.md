
## AI Based Skin Disease Detection System.

<p>
    It is an simple application that analyses dermoscopic images and detects the seven different
    categories skin diseases.

</p>

<ol> 
 <li>
    Actinic keratoses and intraepithelial carcinoma / Bowen's disease (AKIEC)
</li>
<li>
    basal cell carcinoma (BCC),
</li>
<li>
    dermatofibroma (DF),
</li>
<li>
    benign keratosis-like lesions (solar lentigines / seborrheic keratoses and lichen-planus like keratoses, BKL),
</li>
<li>
    melanoma (MEL),
</li>
<li>
    melanocytic nevi (NV),
</li>
<li>
    vascular lesions (angiomas, angiokeratomas, pyogenic granulomas and hemorrhage, VASC).
</li>
</ol>

### AI Techniques Used:
<p> For the project, three deep learning models are implemented that are "Simple CNN" and Transfer learning techniques such as "Xception" and "EfficientNetB0"</p>

### Data Set:
<p> The dataset selected for the project is HAM 10000, which consists of 10,000 images of skin diseases. </p>
